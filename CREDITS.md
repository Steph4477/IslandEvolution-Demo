## 🎵 Main Menu — Level 0

License:  
https://creativecommons.org/publicdomain/zero/1.0/

### Island Evolution versions

- **Explorer:** based on the original CC0 sound.
- **Survivor:** modified version created for Island Evolution, with increased tempo and a darker, more tense atmosphere.
- **King of the Island:** modified version created from the Survivor evolution, with increased intensity, heavier low frequencies and a more threatening atmosphere.

The Survivor and King versions used in Island Evolution are modified versions created from this original CC0 source.
